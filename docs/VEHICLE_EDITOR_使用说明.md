# 车辆型号编辑功能 - 使用说明

## ✨ 新功能

现在 Superuser 可以直接编辑用户的车辆品牌和型号了！

## 🎯 功能位置

```
用户管理 → 选择用户 → 用户详情 → 车辆型号字段
```

## 📱 使用方法

### 1. 查看车辆信息

```
┌─────────────────────────────┐
│ 🚗 车辆型号                 │
│                             │
│ Xpeng P7+                  │
└─────────────────────────────┘
```

### 2. 开始编辑（仅 Superuser）

鼠标悬停在车辆型号上，会看到 **[+]** 图标：

```
┌─────────────────────────────┐
│ 🚗 车辆型号                 │
│                             │
│ Xpeng P7+  [+] ← 点击这里   │
└─────────────────────────────┘
```

### 3. 编辑界面

点击后会出现编辑框：

```
┌─────────────────────────────┐
│ ┌─────────────────────────┐ │
│ │ 品牌: Xpeng             │ │
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 型号: P7+               │ │
│ └─────────────────────────┘ │
│                             │
│ [✓ 保存] [✕ 取消]          │
└─────────────────────────────┘
```

### 4. 智能建议

输入时会显示常用组合：

```
┌─────────────────────────────┐
│ 常用组合                    │
├─────────────────────────────┤
│ • Xpeng P7                  │
│ • Xpeng P7+      ✓          │
│ • Xpeng G9                  │
│ • Tesla Model 3             │
│ • NIO ES6                   │
└─────────────────────────────┘
    ↑ 点击即可快速选择
```

## ⌨️ 快捷键

- **Enter** - 保存
- **Escape** - 取消
- **点击外部** - 自动取消

## 💡 使用技巧

### 1. 快速编辑
直接点击建议列表中的选项，会自动保存！

### 2. 自定义输入
如果建议列表中没有，直接输入新的品牌和型号

### 3. 只改品牌或型号
可以只修改品牌，保持型号不变，或反之

## ⚠️ 注意事项

1. **品牌必填** - 品牌不能为空，型号可以为空
2. **Superuser 专属** - 只有 Superuser 可以编辑
3. **实时保存** - 保存后立即生效

## 🔍 权限说明

### Superuser 看到的界面：
```
Xpeng P7+  [+]  ← 可以点击编辑 ✅
```

### 普通用户看到的界面：
```
Xpeng P7+       ← 只读显示，无法编辑
```

## 📝 常见场景

### 场景 1：用户注册时填错了车型

**步骤：**
1. 找到该用户
2. 点击车辆型号字段的 [+]
3. 修改为正确的品牌和型号
4. 点击"保存"

### 场景 2：用户换车了

**步骤：**
1. 找到该用户
2. 点击车辆型号字段的 [+]
3. 输入新车的品牌和型号
4. 或者从建议列表中选择
5. 点击"保存"

### 场景 3：快速批量修正

**步骤：**
1. 逐个选择需要修正的用户
2. 利用建议列表快速选择
3. 每个用户只需 1-2 次点击

## 🎨 视觉效果

### 悬停效果
- 鼠标悬停时，背景变浅灰色
- 显示蓝色的 [+] 编辑图标

### 编辑状态
- 输入框有蓝色边框
- 保存按钮是绿色
- 取消按钮是灰色

### 建议列表
- 白色卡片，圆角阴影
- 悬停时行背景变浅灰
- 当前值有绿色 ✓ 标记

## 🔧 故障排除

### 问题：看不到 [+] 图标
**原因：** 你不是 Superuser
**解决：** 联系管理员设置权限

### 问题：保存失败
**原因：** 网络问题或权限不足
**解决：** 
1. 检查网络连接
2. 刷新页面重试
3. 查看控制台错误信息

### 问题：建议列表为空
**原因：** 数据库中没有相关记录
**解决：** 直接输入新的品牌和型号即可
