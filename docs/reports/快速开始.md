## ✨ 功能 2：车辆信息编辑（Superuser 专属）

### 界面布局

以 Superuser 身份登录后，在用户详情页面会看到：

```
┌─────────────────────────────────────┐
│ 🛡️ ADAS 品牌                        │
│    Xpeng                [+]         │  ← 点击编辑
├─────────────────────────────────────┤
│ 🚗 车辆型号                          │
│    Xpeng P7+            [+]         │  ← 点击编辑
├─────────────────────────────────────┤
│ 📦 软件版本                          │
│    V1.2.3               [+]         │  ← 原有功能
└─────────────────────────────────────┘
```

### 编辑 ADAS 品牌

1. **点击** ADAS 品牌行的任意位置
2. **下拉选择** 新的品牌
3. **保存** 或按 Enter 键
4. ✅ 品牌立即更新
5. ✅ 车辆型号行的品牌显示自动同步

### 编辑车辆型号

1. **点击** 车辆型号行的任意位置
2. **输入** 新的型号（如 "Model 3"）
3. **可选：** 从建议列表中快速选择
4. **保存** 或按 Enter 键
5. ✅ 型号立即更新

### 快捷键

- **Enter** - 保存
- **Escape** - 取消
- **点击外部** - 自动取消

## 🔍 问题排查

### 问题：看不到编辑图标 [+]

**原因：** 你不是 Superuser

**解决：**
- 联系管理员设置 `is_superuser = true`
- 或者以 Superuser 账号登录

---

### 问题：图片加载失败

**检查：**
1. 打开浏览器控制台（F12）
2. 查看 Network 标签
3. 查找失败的请求
4. 检查图片 URL 是否正确

**可能原因：**
- 网络问题
- 图片文件不存在
- PocketBase 服务未启动

---

### 问题：保存失败

**检查：**
1. 打开浏览器控制台
2. 查看错误信息
3. 确认网络连接
4. 确认有编辑权限

**可能原因：**
- 权限不足（非 Superuser）
- 网络连接中断
- 服务器错误
