## 💡 推荐方案：引入低速补偿因子

### 核心思路

**在低速时适当放宽阈值**，因为：
1. 低速下相同的减速度体感更明显
2. 低速时刹车距离短，风险相对较小
3. 符合真实驾驶体验

### 具体实现

```dart
// 在 motion_processor.dart 中的 _detectRapidAccelDecel 方法

double getSpeedAdjustedThreshold(double baseThreshold, double speedKmh) {
  // 低速补偿（15 km/h以下）
  if (speedKmh < 15.0) {
    // 速度越低，补偿越大
    // 9.5 km/h 时补偿 15%
    // 15 km/h 时补偿 0%
    double compensation = (15.0 - speedKmh) / 15.0 * 0.15;
    return baseThreshold * (1 - compensation);
  }
  return baseThreshold;
}

// 使用：
final speedKmh = speed * 3.6;
final adjustedDecelThreshold = getSpeedAdjustedThreshold(
  config.thresholdDecel * factor * suppressionY * turnComp,
  speedKmh
);

// 原本: -2.0 * 1.0 * 1.0 * 1.0 = -2.0
// 9.5 km/h时: -2.0 * (1 - 0.15 * (15-9.5)/15) = -2.0 * 0.89 = -1.78
// → 可以检测到 -1.902 的事件！
```

## 🎯 关于手动标记位置的疑问

### 为什么你在0秒标记，而不是-6.9秒？

**可能的原因**:

1. **反应延迟**
   - 感受到减速 → 意识到需要标记 → 点击按钮
   - 这个过程大约需要 5-7秒

2. **感受到的是整个过程**
   - -6.9秒: 最大减速点（物理峰值）
   - 0秒: 整个减速过程的结束（体感结束）
   - 你可能标记的是"整个不适过程"而不是"峰值时刻"

3. **视觉vs感觉**
   - 图表显示的是物理加速度峰值
   - 但人的感受可能滞后或综合多个因素
