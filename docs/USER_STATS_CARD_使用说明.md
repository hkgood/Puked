# 用户统计信息功能 - 使用说明

## ✨ 新功能

已认证用户现在可以看到详细的统计信息，替代原来的认证图片显示！

## 📊 显示内容

### 已认证用户（approved）

查看已认证用户时，右侧卡片会显示：

```
┌─────────────────────────────────────┐
│ 📈 上传里程: 1,234.56 km            │
│ 📊 里程贡献度: 0.25%                │
│ 🏆 Puked 排名: #15 / 500           │
│ ⚡ Puked 值: 12.35 km/事件          │
│ 🥧 品牌里程分布（饼图）              │
└─────────────────────────────────────┘
```

### 未认证用户（pending/rejected）

仍然显示认证图片（用于审核）

## 📈 统计指标说明

### 1. 上传里程
用户上传的所有行程的总里程数

### 2. 里程贡献度
用户里程占全球总里程的百分比
```
贡献度 = (用户里程 / 全球总里程) × 100%
```

### 3. Puked 排名
基于 Puked 值的全球排名
- 数字越小，排名越高
- 显示排名和总用户数
- 显示百分位（前 X%）

### 4. Puked 值
衡量驾驶舒适度的指标
```
Puked 值 = 总里程 / 负体验事件数
```
- 数值越高，表示单位里程内负体验越少
- 驾驶体验越舒适

### 5. 品牌里程分布
用户在不同品牌车辆上的里程分布
- 饼图可视化展示
- 鼠标悬停查看详细数据
- 底部显示图例

## 🎯 使用方法

### 查看已认证用户统计

1. 进入用户管理页面
2. 在用户列表中选择一个**已认证**用户
3. 右侧卡片自动显示统计信息

**注意：** 只有已认证（approved）用户才显示统计卡片

### 查看待审核用户

1. 选择一个待审核（pending）或被拒绝（rejected）用户
2. 右侧卡片显示认证图片
3. 用于审核用户身份

## 💡 特殊情况

### 已认证但无统计数据

如果用户已认证但未上传行程数据：

```
┌─────────────────────────────────────┐
│         [图标]                       │
│      暂无统计数据                    │
│  用户需要上传行程数据后才会生成统计  │
└─────────────────────────────────────┘
```

**原因：**
- 用户虽然通过认证，但还没有上传任何行程
- 统计数据由后台任务定期生成
- 需要等待用户上传行程后再次刷新统计

### 数据更新

统计数据不是实时的，由以下方式更新：

1. **手动刷新**
   - 在 Stats Manager 页面点击"刷新用户统计"
   - 会重新计算所有用户的统计数据

2. **自动更新**
   - 后台定时任务定期更新
   - 更新频率由系统配置决定

## 🎨 图表说明

### 品牌里程分布饼图

**功能：**
- 显示用户在不同品牌车辆上的里程分布
- 多彩配色，每个品牌不同颜色
- 百分比自动计算

**交互：**
- 鼠标悬停：显示品牌名称和详细里程
- 底部图例：显示所有品牌和里程数

**示例：**
```
Xpeng: 800 km (65%)
Tesla: 400 km (32%)
NIO: 34.56 km (3%)
```

## 🔍 数据来源

统计数据来自 `user_stats` 表：

```
数据流程：
用户上传行程 
  → trips 表存储行程数据
  → Stats Manager 汇总统计
  → user_stats 表存储统计结果
  → UI 显示统计卡片
```

## ⚠️ 注意事项

### 1. 认证状态决定显示内容
- **已认证（approved）** → 统计卡片
- **待审核（pending）** → 认证图片
- **已拒绝（rejected）** → 认证图片

### 2. 数据更新不是实时的
- 统计数据由后台任务定期生成
- 可能存在几分钟到几小时的延迟
- 需要手动刷新统计才能看到最新数据

### 3. 新用户可能无数据
- 刚注册的用户即使已认证也可能无统计
- 需要等待用户上传行程后才会有数据
- 显示"暂无统计数据"提示
